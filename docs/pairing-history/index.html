Pairing Simulator · Data format

Match History JSON

Each round finished in the pairing simulator is saved as one JSON record holding both rosters, the five locked matchups, and the missions that were banned or played.

Download sample JSON

Overview

  • Saved when: the fifth pairing locks. Undoing out of a finished round removes its record again.
  • Several rounds: a session is an array of these records, numbered by id from 1: [ {"id": 1, …}, {"id": 2, …} ].
  • Where it lives: in the browser's memory only, so a page refresh loses it. Today it leaves the tool only through the Excel export.
  • Not included: the step-by-step History panel. That log is plain English sentences for display, not structured data.

Values, pairing order and quirks

Allowed values

  • Missions (9): Secure, Loot, Transmission, Orb, Reboot, Energy Cells, Download, Stake Claim, Data. Each round bans 3 and plays 5, so 1 goes unused.
  • Map types: Volkus 24, Volkus 25, Tomb World, WTC ITC, each numbered 1–6, for example "Volkus 25:1". Split on : to get the type and number. A round normally has three Volkus tables, one Tomb World and one WTC ITC.
  • Sides are always "A" or "B". Custom team names typed into the tool are stored separately and never appear in the record.

How a round runs

  1. Opening bans: the opening Defender bans one mission, then the Attacker bans one.
  2. Pairings 1–4, each in five steps: the Defender reveals a team, the Attacker offers two, the Defender picks one (the other goes back), the Attacker picks the table, and the Defender picks the mission.
  3. After pairing 3, that pairing's Defender bans one more mission.
  4. Pairing 5 is automatic: the last team on each side meets on the last table, and the Defender picks the mission.

The Defender role alternates. The opening Defender is picked at random and defends pairings 1, 3 and 5.

Things to watch for

  • The pairing 5 matchup has no offeredTeams key at all, not an empty array. Treat it as optional.
  • Nothing records who won or the score. The Excel export leaves a blank "Self-Assessed Score" column for that.
  • bannedMissions doesn't say who banned what. By position: 0 is the opening Defender, 1 is the opening Attacker, and 2 is pairing 3's Defender (the opening Defender again).
