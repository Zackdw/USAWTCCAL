Proposal · Pairing Simulator

Make pairings readable on stream.

A stream view for the pairing simulator, built as a fixed 1080p board that viewers can read, in the same look as the Regional Founders site. The pairing rules and step order stay as they are.

File: docs/pairing-simulator.html Team A navy Team B red Missions light teal

What's wrong today

Five problems on a 1080p capture

Screenshots of the current page in Chromium at 1920×1080, with random rosters and the round just started.

  1. 1

    Text is far too small

    html { font-size: 50% } makes 1rem = 8px, and the live board then shrinks text again.

    Team names7.4px
    Section kickers4.6px
    Count pills3.8px
    Roster status2.7px
    Proposed minimum18px
  2. 2

    The board is buried

    The playmat sits under the hero and the full setup panel, so the operator scrolls on air. About half the frame isn't the board.

  3. 3

    It doesn't look like USA Killteam

    Orange on black with Bebas Neue, Oswald and IBM Plex. The regional site is navy, red and cream with Nunito and Inter.

  4. 4

    Sides are hard to tell apart

    Attacker and defender differ only by a faint blue or gold border, so a viewer can't see who's acting.

  5. 5

    Small bugs and stale copy

    "Waiting for rosters" stays visible during a live round. The hero still describes a past change ("the interface is now a drag-and-drop playmat").

Proposed · Stream view

One fixed 1080p board, no scrolling

Each table tile has a slot for the map image (shown here as a placeholder drawing). The board shows only what matters right now: the current step, the pairings locked so far, which missions are open, banned or used, and which Kill Teams each side still has. No round history. Team A stays on the left in navy and Team B on the right in red. Built for America's scrims between state and regional teams; the matchup and rosters below are examples.

Setup view · operator

Normal page in the regional style

  • Team library, roster picks, missions, swap sides
  • Results, Excel export and action history
  • Settings: the two team names (state or regional teams), background, transparent mode
  • A Go live button opens the stream view

Stream view · on air

Fixed 16:9 canvas for OBS

  • Opens at pairing-simulator.html#stream or with the S key
  • Scales to any window and never scrolls
  • Click to act on air; dragging stays in setup
  • A second window mirrors it over BroadcastChannel, so you can capture one and drive from the other

Plan

Six steps; the first two ship alone

Only the presentation changes. The pairing state, step order and Excel export stay as they are.

  1. Shared brand tokens

    Create docs/assets/brand.css from the founders :root block and import it from founders.css, so the regional site doesn't change.

    Ships alone

  2. Restyle setup

    Remove the orange theme, the 50% root size, the grid overlay and three font families. Map the existing button, panel, pill and card classes to the regional look. Fix the stale copy and the stuck "Waiting for rosters" chip.

    Ships alone

  3. Stream view

    Add a #stream section with its own markup and a render function that reads the existing state. Use click targets on air.

    Largest step

  4. Two-window sync

    Post state changes over BroadcastChannel('pairing') so a capture window and a control window mirror each other.

    Small

  5. Stream settings

    Add the two team names, background (site, broadcast, transparent) and safe-area preview, saved in localStorage. Long regional names wrap to two lines in the column header.

    Small

  6. Screenshot checks

    Use Playwright to capture setup and every stream step at 1920×1080, plus a 1280×720 downscale to check readability.

    Small
